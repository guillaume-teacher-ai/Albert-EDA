## How to download the materials

To download the complete repository:

1. Click the green **Code** button.
2. Select **Download ZIP**.
3. Extract the ZIP file on your computer.

You can also open an individual file and download it separately.

## Important instructions

* Download the files before working on them.
* Do not edit the original files directly on GitHub.
* Follow the submission instructions and deadlines communicated during class.
* Check this repository before each session for newly published materials.
